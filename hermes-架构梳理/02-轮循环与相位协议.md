## 2. `_LoopState` —— **每一个**循环局部变量（`:1385-1420`）

docstring（原文）：

> *"Every local the turn loop threads through the phase helpers in `agent/turn_*.py`.
> Helpers take the loop locals they need as **keyword arguments named like these fields** and return **a verdict whose non-`action`/`result` fields carry the same names**;
> `_run_phase` passes and copies them back **by name**, so **a new helper input/output needs a field here and nothing else**.
> Per-iteration slots are rebound by the phases before any later phase reads them, exactly as the former inline locals were."*

字段分两组：
* **Fixed for the turn**（`:1393-1397`）：`user_message`、`system_message`、`moa_config`、`original_user_message`、`conversation_history`、`effective_task_id`。
* **Per-iteration slots**（`:1399+`）：`request_logger`、`api_messages`、`tools_for_api`、`_moa_prepared_request`、`approx_tokens`、`request_pressure_tokens`、`total_chars`、`thinking_spinner`、`api_start_time`、`retry_count=0`、`max_retries`、`_retry`、`finish_reason="stop"`、`response`（*"None when every retry failed"*）、`api_kwargs`（*"None until built; read by the except handlers"*）、`api_request_id`、`_original_api_kwargs`、`_llm_middleware_trace`、`api_duration`、`assistant_message`。

**另有从 `TurnContext` 播种的字段**（`_CTX_FIELDS`，`:1444`）：`user_message`、`original_user_message`、`conversation_history`、`effective_task_id`、`turn_id`、`_should_review_memory`、`_plugin_user_context`、`_ext_prefetch_cache`、`messages`、`active_system_prompt`、`current_turn_user_idx`、`_preflight_compression_blocked` —— 注释：*"same name minus the leading underscore"*。

## 3. `_run_phase` —— 相位调用器（`:1480-1498`）

```python
def _run_phase(fn, agent, state: _LoopState, **extra):
    """Call phase helper ``fn`` with the loop locals it names, copy its verdict fields back.

    ``extra`` supplies non-state arguments (the caught exception). Returns the verdict so
    the caller can act on ``.action`` / ``.result``."""
    params = _PHASE_PARAMS.get(fn)
    if params is None:
        params = _PHASE_PARAMS[fn] = tuple(p for p in inspect.signature(fn).parameters if p != "agent")
    verdict = fn(agent, **{n: extra[n] if n in extra else getattr(state, n) for n in params})
    latched = _LATCHED_VERDICT_FIELDS.get(getattr(fn, "__name__", ""), ())
    for f in fields(verdict):
        if f.name in ("action", "result"):
            continue
        value = getattr(verdict, f.name)
        if f.name not in latched:
            setattr(state, f.name, value)
        elif value:
            setattr(state, f.name, True)
    return verdict
```

要点：
* **按参数名装配**：`inspect.signature(fn)` 去掉 `agent`，其余参数名逐个从 `state` 取（`extra` 优先）。
* **缓存**：`_PHASE_PARAMS: Dict[Any, tuple]`（`:1445`）按函数对象缓存，不重复内省。
* **verdict 回写**：除 `action`/`result` 外，verdict 的每个字段**按名写回 state**。
* **latch 语义**：`_LATCHED_VERDICT_FIELDS = {"handle_api_error": frozenset({"_provider_overflow_recovery_pending"})}`（`:1449-1450`）。注释原文：*"Verdict fields the loop latches (**only ever sets True**) instead of copying back: `handle_api_error` reports overflow recovery per call and **must not clear an earlier arm**."*

**⇒ 这是全套设计里最可移植的一条：相位的输入输出**不靠函数签名传递**，靠**同名的 state 字段**。新增一个相位不需要改任何调用点。**

## 4. Verdict 协议：`action` ∈ {ok, continue, break, return}（+ 可选 `result`）

每个相位模块自带 verdict 类，形状统一：

| 模块 | 类 | 行 |
|---|---|---|
| `agent/turn_api_call.py` | `ApiCallVerdict` | :37 |
| `agent/turn_api_call.py` | `ApiInterruptVerdict` | :161 |
| `agent/turn_api_call.py` | `NousRateGuardVerdict` | :216 |
| `agent/turn_api_error.py` | `ApiErrorVerdict` | :32 |
| `agent/turn_api_error.py` | `UnrecoveredErrorVerdict` | :241 |

每个模块还有私有 `_verdict(action, result=None)` 构造器（`turn_api_call.py:77,235`、`turn_api_error.py:65`）。

**调用点的动作映射**（全循环一致，这是唯一的控制流词汇）：

| action | 调用点做的事 |
|---|---|
| `"ok"` | 继续下一个相位 |
| `"continue"` | `continue` 主 while（重开一次迭代） |
| `"break"` | `break` 出主 while，走 `finalize_turn` |
| `"return"` | 立即 `return verdict.result`（带着结果结束整个 turn） |

主循环里的实例：`:1642-1647`（`run_preflight_gate` 用全四种：return/break/continue/ok）、`:1666-1678`（`normalize_model_response` 用 return/continue，`run_tool_round`/`finish_text_response` 用 return/break/continue）。

## 5. `_run_api_retry_loop` —— **一次** API 调用及其重试/恢复（`:1501-1530`）

docstring：*"One API call with its retry/recovery loop (guard → build → call → check, error handlers). Returns a turn result dict when a phase ends the turn, else None once the loop is left (success, a restart armed on `s._retry`, interrupt, or retries exhausted)."*

```python
while s.retry_count < s.max_retries:
    _ng = _run_phase(nous_rate_limit_guard, agent, s)
    if _ng.action == "return": return _ng.result
    if _ng.action == "break":  return None
    try:
        _run_phase(build_api_request, agent, s)
        if _run_phase(perform_api_call, agent, s).action == "break": return None
        _rc = _run_phase(check_api_response, agent, s)
        if _rc.action == "return": return _rc.result
        if _rc.action == "break":  return None
    except InterruptedError:
        if _run_phase(handle_api_interrupt, agent, s).action == "break": return None
    except Exception as api_error:
        _ae = _run_phase(handle_api_error, agent, s, api_error=api_error)
        if _ae.action == "return": return _ae.result
        if _ae.action == "break":  return None
return None
```

**要点**：异常在**这一层**被捕获并**翻译成 verdict**（`handle_api_error`）；`handle_api_interrupt` 单独处理 `InterruptedError`。**没有裸异常穿透到主循环**（主循环另有兜底，见 §6）。

## 6. 主循环（`:1636-1681`）

```python
while (s.api_call_count < agent.max_iterations and agent.iteration_budget.remaining > 0) \
        or agent._budget_grace_call:
    if _run_phase(begin_iteration, agent, s).action == "break": break
    _run_phase(prepare_iteration, agent, s)
    _run_phase(assemble_api_request, agent, s)
    _pg = _run_phase(run_preflight_gate, agent, s)
    if _pg.action == "return":   return _pg.result
    if _pg.action == "break":    break
    if _pg.action == "continue": continue
    _run_phase(announce_api_call, agent, s)

    s.api_start_time, s.retry_count, s.max_retries = time.time(), 0, agent._api_max_retries
    s._retry, s.finish_reason, s.response, s.api_kwargs = TurnRetryState(), "stop", None, None
    s.api_request_id = agent._current_api_request_id = f"{s.turn_id}:api:{s.api_call_count}"

    early_result = _run_api_retry_loop(agent, s)
    if early_result is not None:
        return early_result

    _rs = _run_phase(apply_retry_restarts, agent, s)
    if _rs.action == "break":    break
    if _rs.action == "continue": continue

    try:
        _ri = _run_phase(normalize_model_response, agent, s)
        if _ri.action == "return":   return _ri.result
        if _ri.action == "continue": continue
        _v = _run_phase(
            run_tool_round if s.assistant_message.tool_calls else finish_text_response, agent, s
        )
        if _v.action == "return":   return _v.result
        if _v.action == "break":    break
        if _v.action == "continue": continue
    except Exception as e:
        if _run_phase(handle_outer_loop_error, agent, s, e=e).action == "break":
            break
```

**唯一按条件选择相位的地方**是 `run_tool_round if s.assistant_message.tool_calls else finish_text_response`（`:1670-1672`）—— 一个 **2 路**选择，不是 if/elif 阶梯，符合形状规则（`AGENTS.md:252`）。

**循环条件**与 `agent/AGENTS.md:26-27` 的文档心智模型一致：`api_call_count < max_iterations AND iteration_budget.remaining > 0`，**OR** `_budget_grace_call`（一次宽限调用）。中断检查不在 while 头，而在 `begin_iteration` 相位内（`if _run_phase(begin_iteration, agent, s).action == "break"`）。

## 7. 收尾：`finalize_turn`（`:1683-1692`）

```python
# Post-loop finalization lives in agent/turn_finalizer.finalize_turn.
result = finalize_turn(agent, **{
    name: getattr(s, name)
    for name in inspect.signature(finalize_turn).parameters if name != "agent"
})
if s._compression_timeout_exhausted:
    # Reuse the gateway's context-recovery contract: transcript stays intact while
    # future input can move to a clean session (#98722).
    result.update(error=_COMPRESSION_TIMEOUT_FINAL_RESPONSE, partial=True, compression_exhausted=True)
return result
```

**注意**：`finalize_turn` 的参数也是**按签名从 state 取**的——与 `_run_phase` 同一套约定，但它是**显式**调用（不在相位表里）。这是"一条 `return` 路径汇集所有出口"的落点：主循环的 `break`、预算耗尽、以及所有 `action=="break"` 都到这里。

## 8. 公共入口：`run_conversation`（`:1695-1742`）

签名 13 个参数（`user_message`、`system_message`、`conversation_history`、`task_id`、`stream_callback`、`persist_user_message`、`persist_user_timestamp`、`persist_user_display_kind`、`persist_user_display_metadata`、`persist_user_platform_id`、`moa_config`、`turn_author`、`title_user_message`）。

docstring 原文：
> *"Run one turn (see `_run_conversation_turn`) and **export the current-turn boundary**.
> **Every envelope that leaves the loop** — success, partial/error, interrupt, retry-exhausted, tool-limit, preflight timeout, codex runtime — **passes through here**, so the `{turn_id, current_turn_user_idx}` pair is **stamped beside the exact `messages` it addresses, after every history rewrite including post-turn micro-compaction**."*

函数体三件事：
1. `with native_turn_images(user_message):` —— *"Images attached natively to this user turn stay visible to vision_analyze for the turn, so it does not embed the same pixels a second time into the same request (#76411)."*
2. `result = _run_conversation_turn(...)`
3. `result = export_current_turn_boundary(agent, result, user_message)`；`_close_durable_failed_turn(agent, result)`（`:1745`，*"Append a Hermes-authored assistant boundary when a failed turn left `user` as the [last row]"* —— 与 `turn_tool_validation.py:1-8` 的 tool-result 尾约束同源）。

**⇒ `.action=="return"` 的 8 个出口全部汇到这一层盖章，不存在"某条出口忘了记边界"的可能。这是"多轮跑得通"的机械保证。**

## 9. codex 旁路（`:1620-1634`）

`api_mode == "codex_app_server"` 时整个 turn 交给 codex app-server 子进程（`agent/transports/codex_app_server_session.py`）；`activate_codex_app_server_fallback` **返回 True 表示已回退**（改写 provider/model/api_mode），于是**同一个 user turn 在下面的通用循环里重跑**，`s.api_call_count` 从 codex 结果接续、`active_system_prompt` 用 `_sync_failover_system_message` 对齐。注释：*"keeping codex's projected rows and its failed API call in the turn's accounting."*

## 10. 从这一册能直接读出的架构结论

1. **一轮 = 一个 State + 一串同构相位 + 一个循环 + 一个收尾。** 相位之间**零直接耦合**（不互相调用，全部通过 state 字段 + verdict 字段通信）。
2. **控制流词汇只有一个 `action`**（ok/continue/break/return）。所有相位用同一个词表，所以主循环的每个分支都是同构的 if 三连。
3. **异常不允许穿透**：`_run_api_retry_loop` 捕获 API 异常→verdict；主循环再捕获相位异常→`handle_outer_loop_error` 相位。
4. **新增相位零调用点改动**：加函数 + 在 `_LoopState` 加需要的字段即可（`_run_phase` 内省签名）。**唯一需要手改的是主循环里的相位顺序**。
5. **出口唯一**：所有 return 都经 `finalize_turn`（循环内 break）或 `run_conversation`（边界盖章）。
6. **`_LATCHED_VERDICT_FIELDS` 是唯一特例**，且特例本身被显式登记在表里，而不是散在代码里的 flag。

**⇒ 对 tsm-agt 的直接启示（事实对照，非方案）**：Hermes 的"一轮"之所以跑得通，不是因为它把逻辑想全了，而是因为
(a) 相位的**输入输出按名字**而非按位置传递，
(b) 控制流只有**一个枚举**，
(c) 异常在**最近的一层**被翻译成同一枚举，
(d) 出口**只有一个**。

这四条都不依赖 Hermes 的任何领域概念。
