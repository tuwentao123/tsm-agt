# 01 · Hermes 上下文构建 / 会话拼接 / 会话状态

> 来源 `/tmp/hermes-src`。每条带 `file:line`。本文合并原计划的 ①（上下文与 prompt）与 ②（会话与状态）——因为源码里这两件事是**同一条代码路径**：`build_api_messages` 从会话消息行拼出 wire 副本。

## 1. 最重要的结构事实：三份 messages 是分开的

源码里同时存在三样东西，**永不混淆**：

| 名字 | 是什么 | 谁写 | 谁读 |
|---|---|---|---|
| `messages` | **durable transcript**（含 thinking、含工具行） | 循环追加 | `_flush_messages_to_session_db` 持久化 |
| `api_messages` | **本次请求的 wire 副本**，逐次调用重建 | `build_api_messages` + `assemble_api_request` | 只发给 provider |
| `api_content` | 每行**当时真实发出的字节**（sidecar 列） | 发送时盖戳 | 下一轮重放该行的 `content` |

`agent/turn_context.py:1197-1206` 原文：

> *"Build the wire copy of ``messages`` for one API call plus the effective system message. **Prompt-cache invariant**: historical user/assistant rows replay their ``api_content`` sidecar (the exact bytes sent live) so the prefix stays byte-stable; the current user turn reuses the prologue's stamp (or composes live when a caller bypassed the prologue). **Ephemeral context** (prefetch, ``pre_llm_call`` hooks, ``ephemeral_system_prompt``) **is added at API time only** — ``messages`` stays untouched beyond the sidecar stamp, and **the system prompt is built ONCE per session and replayed verbatim**."*

**⇒ 没有"上下文构建器"这种组件。** 上下文 = 持久 transcript 的函数，加一层只作用于 wire 的临时注入。

## 2. `build_api_messages`（`turn_context.py:1193-1297`）

签名返回 `(api_messages, effective_system)`。逐步：

1. `split = current_turn_user_idx`；**本轮之前的行**才过 `canonicalize_replay_history(..., now=turn_now)`，本轮之后追加的行是"活的"，**绝不重写**（`:1224-1225`）。注释：*"the request copy must carry the same bytes or a resume diverges mid-prefix."*
2. 逐行 `_clone_message_for_send(msg)` —— **结构克隆，不是 `msg.copy()`**，因为后面的原地改写不能透过嵌套容器写回持久历史（`:1229-1231`）。
3. `api_msg.pop("api_content")` —— *"``api_content`` is bookkeeping (exact bytes sent), **never a provider field**"*；再 pop 掉全部 `PERSISTENCE_ONLY_MESSAGE_FIELDS`（`display_*`/`_row_id`/`timestamp`），因为*"strict OpenAI backends reject unknown keys"*（`:1237-1239`）。
4. **本轮 user 行**：有 sidecar 就重放 sidecar（保证"sidecar 与 wire 不可能漂移"），没有才 `compose_user_api_content(...)` 现拼（`:1243-1254`）。
5. **历史 user/assistant 行**：重放 sidecar 字节（`:1255-1262`）。
6. `_copy_reasoning_content_for_api` 给**所有** assistant 行回传 reasoning；再 pop `reasoning`/`finish_reason`（`:1264-1270`）。
7. `fill_empty_non_final_wire_payload(api_msg, is_final=...)` —— 补空行，**durable history 不动**（"so the pre-call sanitizer stops re-healing and flooding errors.log"）（`:1271-1274`）。
8. 按需 `_sanitize_tool_calls_for_strict_api`（`:1281-1283`）。
9. **最后**才拼 system：`effective_system = active_system_prompt or ""`，再把 `agent.ephemeral_system_prompt` 追加进去（`:1289-1296`）。

关键注释（`:1287-1288`）：*"Plugin/recall context goes into the **user message**, never the system prompt: the prompt is built ONCE per session and replayed verbatim (stable cache prefix)."*

## 3. `assemble_api_request`（`turn_request_assembly.py:106-266`）

docstring（`:111-113`）原文：*"Assemble the request in the original order. **ORDER IS LOAD-BEARING**: cache breakpoints are injected only **after** whitespace normalization, the orphan sweep, thinking-only drop / user merge and surrogate stripping, so the same row's bytes never vary across turns."*

固定顺序（这就是"会话拼接"的全部）：

| # | 步骤 | 行 |
