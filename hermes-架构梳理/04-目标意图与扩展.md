## 2. `GoalContract` —— 5 个自由文本字段（`:287-310`）

```python
class GoalContract:
    """Optional structured completion contract; empty fields are omitted everywhere."""
    outcome: str = ""
    verification: str = ""
    constraints: str = ""
    boundaries: str = ""
    stop_when: str = ""
```

* `is_empty()`：全部字段去空白后为空即空契约；
* `to_dict()` / `from_dict()`（逐字段 `str(...).strip()`）；
* `render_block()`：**只渲染非空字段**成 `- <label>: <value>` 的 bullet 块；**空契约 → 空字符串**（不注入）。

**字段别名表**（`:274` 起）：`"outcome": "outcome", "goal": "outcome", "done": "outcome", "done when": "outcome", ...`

**`parse_contract(text) -> (headline, GoalContract)`**（`:312-335`）规则原文：

> *"Split user-typed goal text into a headline + contract from inline ``field: value`` lines. A headline without an explicit ``outcome:`` **IS** the outcome — it is not duplicated into the contract block (the goal text already carries it), so outcome stays empty in that case."*

实现：逐行看 `:`，前缀命中 `_CONTRACT_ALIASES` 且值非空 → 归入该字段；否则进入 headline。字段值以空格 join。

**⇒ 契约只能从用户输入"提取"，不能由模型"发明"；没有显式字段就不造。**

## 3. `GoalGate` —— 唯一机器可判定的判据（`:344-372`）

```python
@dataclass
class GoalGate:
    """A deterministic shell command that must pass before a goal can be done.

    Gates run at turn boundary BEFORE the LLM judge; a failing gate short-circuits judging and its
    bounded output becomes the continuation prompt."""
    command: str
    timeout_seconds: int = DEFAULT_GATE_TIMEOUT_SECONDS   # 300（:51）
    max_retries: int = DEFAULT_GATE_MAX_RETRIES           # 3（:52）
    attempts: int = 0
    last_exit_code: Optional[int] = None
    last_output_tail: str = ""
```

状态里 gate 是**列表**（`GoalState.gates: List[GoalGate]`），注释写明：

> *"`/goal gate add <cmd>`: **ALL** must pass before the judge may declare done."*（`:448-449`）

**`run_gate(gate, *, cwd) -> (passed, exit_code, output_tail)`**（`:396-417`）：

```python
subprocess.run(gate.command, shell=True, capture_output=True, text=True,
               encoding="utf-8", errors="replace",
               timeout=max(1, int(gate.timeout_seconds)), cwd=cwd or None)
return proc.returncode == 0, proc.returncode, combined[-_GATE_OUTPUT_TAIL_CHARS:]
# TimeoutExpired → (False, -1, out + "[gate timed out after Ns]")
# 其它异常      → (False, -1, "[gate could not run: <type>: <msg>]")
```

`utf-8/errors="replace"` 的注释：*"operator-configured output is arbitrary bytes; strict codepage decoding of one unmappable byte (emoji/CJK on a non-UTF-8 Windows console) kills the reader thread and the tail the agent needs arrives empty."*

**`_gate_workspace() -> (cwd, refusal)`**（`:374-394`）：gate 在**被声明的 session workspace** 里跑；若声明的 workspace 在本机不是目录 → **拒绝并暂停，不重试**，原文：

> *"a relative gate run anywhere else would check a different project and could pass a failing goal, **and no agent turn can fix it**, so the caller pauses instead of retrying."*

无声明 workspace 时回退 `resolve_agent_cwd()`（= `TERMINAL_CWD`，否则启动目录）。

## 4. `GoalState` —— 每会话持久状态（`:419-449`）

```python
class GoalState:
    goal: str
    status: str = "active"        # active | paused | done | cleared
    turns_used: int = 0
    max_turns: int = DEFAULT_MAX_TURNS            # 20（:32）
    created_at: float; last_turn_at: float
    last_verdict: Optional[str]                   # "done" | "blocked" | "continue" | "wait" | "skipped"
    last_reason: Optional[str]
    paused_reason: Optional[str]                  # why we auto-paused (budget, etc.)
    consecutive_parse_failures: int = 0           # judge-output parse failures in a row
    consecutive_transport_failures: int = 0       # judge API/transport errors in a row
    subgoals: List[str]                           # 用户 /subgoal 追加的判据
    waiting_on_pid / waiting_on_session / waiting_until / waiting_on_delegations
    waiting_reason / waiting_since
    contract: GoalContract
    gates: List[GoalGate]
```

注释里的三条要点：

* `consecutive_transport_failures`：*"a broken API key returns 401 every call and must auto-pause instead of burning the budget on an unreachable judge."*
* `subgoals`：*"User-added criteria (/subgoal). **Both the judge and continuation prompts include them.**"*
* `waiting_*`（Wait barrier）：*"parks the loop instead of re-poking the agent into busy-work … While ANY is active `evaluate_after_turn` returns `should_continue=False` without burning a turn; cleared lazily when satisfied or by unwait/pause/resume/clear."*

**状态转换点（行号）**：`cleared` :675 / :1206；`paused` :1159 / :1188；`active` :1196（resume）；`done` :1213 / :1534。
**序列化**：`to_json()`/`from_json()` 逐字段强转（int/float/bool 容错），保证旧 `state_meta` 行仍可装载（`:456-475`）。

## 5. 判定链：gate → judge → decision

| 函数 | file:line | 作用 |
|---|---|---|
| `judge_goal(...)` | `:893` | 让 LLM 判 goal 是否达成 |
| `_decision(status, should_continue, prompt, verdict, reason, message)` | `:1077-1079` | 统一返回 `{"status", "should_continue", "continuation_prompt", ...}` |
| `evaluate_after_turn(...)` | `:1479` | docstring 原文：*"**Run gates + judge and update state.** Return a decision dict (`status`, `should_continue`, …)"* |
| 预算检查 | `:1502` | `if gate_decision.get("should_continue") and state.turns_used >= state.max_turns:` |

**判官要求的输出形状**（提示词原文 `:164`）：

```
'{"verdict": "done", "reason": "<one sentence>"}'
```

即：**一个 verdict + 一句理由**，verdict 取值见 `last_verdict` 的 5 值（`done|blocked|continue|wait|skipped`）。**没有按 criterion 分类的判据体系。**

契约块如何进提示（`:68`、`:263` 附近注释）：*"With a completion contract: the block tells the agent what 'done' means, how to prove it, what must not regress, what is in bounds, when to stop and ask."*

## 6. 源码直接支持的推论（机械推论，非建议）

1. **契约是用户的**：`parse_contract` 只从用户文本提取，模型不参与生成；没写就没有。
2. **机器可判定的只有 gates**：`run_gate` 只看退出码；gate 是列表且"全部通过"才允许判官判 done。
3. **顺序固定**：gates → judge；gate 失败**短路**判官，且**其有界输出直接作为续跑提示**。
4. **不可由 agent 修复的条件 → 暂停**（workspace 不存在），因为"an agent turn can't fix it"。
5. **判官本身的故障会被计数并自动暂停**（parse/transport 连续失败），不允许空烧预算。
6. **`waiting_*` 屏障**：等待期间 `should_continue=False` 且**不消耗 turn**，避免空转。
7. **goal 状态只有 4 个值**，`turns_used/max_turns`（默认 20）是唯一的轮次预算。
